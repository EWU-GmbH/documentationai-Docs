## Creating a Project

To organize your docs in EWU:

1. Log in to `https://ewu.com`
2. Click **"New Project"** top-right
3. Enter a project name and description
4. Click **"Create"**
5. Add your first page or upload existing docs

## Accessing your project

- Your new project appears on the dashboard
- Click its name to manage docs and settings
