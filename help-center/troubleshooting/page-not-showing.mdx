---
title: Documentation Page Not Showing
description: Fix missing documentation pages in EWU.
---

## Symptoms

- Created doc page is not visible in project
- Page link returns 404

## Quick Fix

<Steps>
  <Step title="Refresh Project">
    Use browser refresh or click the project in the sidebar.
  </Step>
  <Step title="Check Visibility">
    Ensure the page is **published** (not draft) in page settings.
  </Step>
  <Step title="Clear Cache">
    Log out and log back in, or clear browser cache if problem persists.
  </Step>
</Steps>
