## Overview

EWU provides a centralized space for your teams to create, organize, and manage project documentation. You can build structured docs with version control, search, and collaboration features. Whether documenting APIs, user guides, or internal processes, EWU keeps everything accessible and up-to-date.

Use EWU to streamline knowledge sharing, reduce onboarding time, and ensure consistency across your projects.

## Quick Start

Get up and running with EWU in minutes.

<Steps>
  <Step title="Sign Up" icon="user-plus">
    Create your free account at `https://app.ewu.com/signup`.
  </Step>
  <Step title="Create Workspace" icon="package">
    Set up a new workspace for your project.
    
    ```bash
    npx create-ewu-workspace my-docs
    cd my-docs
    ```
  </Step>
  <Step title="Add First Page" icon="plus">
    <CodeGroup tabs="CLI,UI">
      ```bash
      ewu pages create introduction.mdx
      ```
      ```typescript
      // Edit introduction.mdx with your content
      const frontmatter = {
        title: "Welcome",
        description: "Overview page"
      };
      ```
    </CodeGroup>
  </Step>
  <Step title="Publish" icon="globe">
    Deploy your docs to a live URL.
    
    ```bash
    ewu deploy
    ```
  </Step>
</Steps>
