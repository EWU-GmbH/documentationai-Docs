## Overview

These integrations streamline your documentation workflow, automate updates, and keep your team aligned.

## Setting Up Webhooks for Notifications

Webhooks enable real-time updates from EWU to your services. Configure them in your project settings to notify tools like Slack or Discord on doc changes.

<Steps>
  <Step title="Navigate to Settings" icon="settings">
    Go to your project dashboard, then select `Integrations` > `Webhooks`.
  </Step>
  <Step title="Add Webhook URL" icon="plus">
    Enter your webhook endpoint, e.g., `https://your-webhook-url.com/ewu-events`.
  </Step>
  <Step title="Select Events" icon="zap">
    Choose events like `doc.updated` or `page.published`.
  </Step>
  <Step title="Test and Save" icon="check-circle">
    Send a test payload and activate the webhook.
  </Step>
</Steps>

Here is an example payload your endpoint receives:

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  {
    "event": "doc.updated",
    "projectId": "proj_123",
    "pageId": "page_456",
    "timestamp": "2024-01-15T10:30:00Z",
    "user": {
      "id": "user_789",
      "email": "user@example.com"
    }
  }
  ```
  ```python
  {
    "event": "doc.updated",
    "projectId": "proj_123",
  ```

## Embedding External Content

Embed live content from other services to enrich your docs without leaving EWU.

<Tabs>
  <Tab title="GitHub Gist" icon="code">
    Use the embed code from any Gist:
    
    ```
    <script src="https://gist.github.com/user/abc123.js"></script>
    ```
    
    Paste it into an `Embed` block in your page editor.
  </Tab>
  <Tab title="Figma" icon="figma">
    Copy the embed URL from Figma:
    
    `https://www.figma.com/embed?embed_host=docs.example.com&url=...`
    
    Add it via the embed dialog.
  </Tab>
  <Tab title="Google Docs" icon="file-text">
    Generate an embed iframe:
    
````html
<iframe src="https://docs.google.com/document/d/e/YOUR_DOC_ID/pub?embedded=true"></iframe>
````
    
    Supports read-only public docs.
  </Tab>
</Tabs>

## API Access for Custom Extensions

Build custom integrations using EWU's REST API at `https://api.example.com/v1`.

<Callout kind="tip">
Obtain your `{API_KEY}` from `Settings` > `API Tokens`. Keep it secure.
</Callout>

<ParamField path="projectId" param-type="string" required="true">
  Your project identifier.
</ParamField>

<ParamField header="Authorization" param-type="string" required="true">
  `Bearer YOUR_API_KEY`
</ParamField>

Example: Fetch pages via API.

<Request tabs="cURL,JavaScript">
  ```bash
  curl -X GET https://api.example.com/v1/projects/{projectId}/pages \
    -H "Authorization: Bearer YOUR_API_KEY"
  ```
  ```javascript
  const response = await fetch('https://api.example.com/v1/projects/{projectId}/pages', {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  });
  const pages = await response.json();
  ```
</Request>

<Response tabs="200">
  ```json
  {
    "pages": [
      {
        "id": "page_456",
        "title": "Integrations",
        "slug": "integrations",
        "updatedAt": "2024-01-15T10:30:00Z"
      }
    ]
  }
  ```
</Response>
