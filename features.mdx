## Overview

EWU provides a comprehensive set of tools to manage your project documentation effectively. You can create, edit, collaborate, and organize docs in a centralized space. Key features include intuitive editing, real-time collaboration, version history, powerful search, and flexible import/export options.

<Callout kind="tip">
  Start by creating your first document to experience these features hands-on.
</Callout>

## Document Creation and Editing Tools

Create new documents quickly and edit them with advanced Markdown support, including components like `<Callout>` and code blocks.

<Steps>
  <Step title="Create a Document" icon="plus">
    Navigate to your workspace and click the `+ New Document` button.
  </Step>
  <Step title="Edit Content" icon="edit">
    Use the visual editor or switch to Markdown mode for full control.
  </Step>
  <Step title="Add Components" icon="layers">
    Insert JSX components directly in MDX files.
  </Step>
</Steps>

Here is a sample code block for a simple document:

```markdown
# My Project Doc

Welcome to your EWU document.

- Feature one
- Feature two
```

## Collaboration and Sharing Options

Invite team members and share docs securely. EWU supports role-based access and real-time editing.

<Tabs>
  <Tab title="Invite Users" icon="user-plus">
    Go to document settings and add emails. Assign roles like `Editor` or `Viewer`.
  </Tab>
  <Tab title="Public Sharing" icon="globe">
    Generate a shareable link with view-only access. Embed docs on external sites.
  </Tab>
  <Tab title="Team Workspaces" icon="users">
    Create workspaces for projects. Manage permissions at the folder level.
  </Tab>
</Tabs>

<Callout kind="info">
  Real-time cursors show who is editing, reducing conflicts.
</Callout>

## Version Control and History Tracking

EWU automatically saves versions, allowing you to revert changes or compare diffs.

<Expandable title="View Version History" default-open="true">
  Click the history icon in the editor toolbar. Select a version to restore or compare side-by-side.
</Expandable>

| Action | Description |
|--------|-------------|
| Restore | Revert to a previous version |
| Compare | See diff highlights |
| Branch | Create a new version branch |

## Search and Navigation Features

Search across all documents with full-text indexing. Use filters for tags, authors, or dates.

```javascript
// Example search query syntax
search("karriere coaching") // Matches titles and content
```

Navigation sidebar shows hierarchy, with breadcrumbs for deep pages.

## Export and Import Options

Export docs to PDF, HTML, or Markdown. Import from GitHub, Notion, or ZIP archives.

<CodeGroup tabs="Markdown,HTML,PDF">
  ```bash
  # Export via CLI
  ewu export --format=md project-docs/
  ```
  ```bash
  # HTML export
  ewu export --format=html --output=docs-site/
  ```
  ```bash
  # PDF generation
  ewu export --format=pdf all-docs/
  ```
</CodeGroup>

<Callout kind="success">
  Imports preserve structure, links, and images automatically.
</Callout>
