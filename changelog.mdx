## Upgrading to the Latest Version

Follow these steps to upgrade EWU smoothly and avoid disruptions.

<Steps>
  <Step title="Backup Your Data" icon="database">

    Create a full backup before proceeding.

````bash
ewu backup --all --output=/path/to/backup
````

  </Step>
  <Step title="Update Package" icon="download">

    <Tabs>
      <Tab title="npm" icon="package">
````bash
npm install ewu@latest
````
      </Tab>
      <Tab title="Docker" icon="docker">
````bash
docker pull ewu:latest
docker-compose up -d
````
      </Tab>
    </Tabs>

  </Step>
  <Step title="Run Migrations" icon="git-merge">

    Apply database changes.

````bash
ewu migrate --env=production
````

  </Step>
  <Step title="Verify Installation" icon="check-circle">

    Test key endpoints.

    <CodeGroup tabs="cURL,JavaScript">
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" https://api.example.com/v1/status
```
```javascript
const response = await fetch('https://api.example.com/v1/status', {
  headers: { 'Authorization': 'Bearer YOUR_TOKEN' }
});
console.log(await response.json());
```
    </CodeGroup>

  </Step>
</Steps>

<Callout kind="tip">
After upgrading, review the [migration guide](https://docs.example.com/migration) for version-specific changes.
</Callout>
